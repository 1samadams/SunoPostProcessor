SUNO::ANALYZER · HELP

HOW IT WORKS

  1. Drop a file — WAV, FLAC, AIFF, OGG or MP3. The whole track is analysed on upload.
  2. AUTO sets a starting point — the smart tuner picks a de-harsh preset, the mud cut, and (only if it hears sibilance) de-ess, and shows the reason for each under AUTO. Tap NUMBERS there to see the measurements.
  3. Tune & A/B — preview a 10/15/30 s clip (scrub to any start). Switch SOURCE between A·ORIG (your file, level-matched), B·PROC (processed) and C·REM (exactly what's removed). Nudge the preset/intensity, or open ADVANCED / FINALIZE for hand-tuning.
  4. Export — render the full track to your chosen format and download it with a before/after report card.

GLOSSARY

LUFS
Perceived loudness (ITU-R BS.1770). We normalize to −14 LUFS, Spotify's streaming target, so tracks sit at a consistent level.
True peak (dBTP)
The real peak including inter-sample peaks (measured 4× oversampled). Held at −1 dBTP so playback won't clip.
De-harsh
Tames the metallic 3–6 kHz sheen from AI generation. Mostly dynamic (acts on spikes) plus a small always-on cut for steady sheen.
De-ess
Tames harsh vocal sibilance (~5–9 kHz “ess”/“tss”), dynamically and only on the peaks. Suggested only when real sibilance is detected.
Mud cut
A small, wide 200–400 Hz cut for low-mid boxiness. Automatic, depth set per track.
Glue / warmth
Optional mastering finish: gentle bus compression + soft valve/transformer saturation. Adds density/warmth; off by default.
Intensity
Scales the active de-harsh preset (0–150%). 0 = bypass, 100 = as tabled, higher = grabs more.
REM (Removed)
Plays exactly what the processing takes out, amplified. Only hiss/sizzle = surgical; music/vocals = cutting too much.
Harshness index
A 0–100 gauge of how much the top end pokes above the mids. Watch the before→after direction, not the absolute number.

Everything except loudness & mud is tunable. The tuner never overrides a choice you make — change any control and it steps aside.
